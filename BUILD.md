# Build instructions

1. Install Hexcells Infinite through Steam and select `Manage`→`Browse local files` to open your installation directory.
1. Copy the `Hexcells Infinite_Data` directory to this repository.
1. Open `HexcellsInfiniteRandomizer.csproj` in Visual Studio and build.
1. Get the latest 32-bit release of [c-wspp-websocket-sharp](https://github.com/black-sliver/c-wspp-websocket-sharp) and replace `websocket-sharp` with it.
